# 《五行守阵》作品介绍（参赛草稿）

建议作品名称：五行守阵——融合五行文化与地形布阵的三维策略塔防游戏

建议赛项：自主选题／虚拟现实（VR/AR/MR/XR）与游戏类。

版本：1.1.0，整理日期：2026 年 10 月 17 日。

## 可用于报名系统的简要介绍

《五行守阵》是一款以五行文化为创作灵感的东方玄幻三维策略塔防游戏。玩家从金、木、水、火、土中选择本命元素，通过布置防御塔抵御敌人，在战斗中获得元素核心，并在独立布阵与元素融合之间作出选择。作品结合元素克制、十种双元素融合、地形阵位和精英、Boss 波次，形成围绕资源分配与阵型调整的战斗体验。游戏采用 Three.js 呈现浮空岛、元素塔与敌人，提供网页版与 Android APK；首页和择境页面以 AI 辅助生成美术统一视觉表达，保留可操作的实际游戏界面。作品探索传统文化意象转化为策略规则和交互体验的设计方法。

## 1. 创作背景与定位

作品面向喜欢短局策略、元素搭配与东方幻想题材的玩家，尝试将五行之间的关系转化为可观察、可选择的战斗规则。玩家需要根据敌人属性、地图路线与有限阵位，决定升级既有塔、扩大防御覆盖，或将获得的元素用于融合。

传统五行关系是灵感来源；雷霆、寒冰、蒸汽等融合形态属于本作的幻想设定，不作为传统文化知识结论呈现。

## 2. 建议突出三项设计特点

1. **元素获取与融合选择。** 开局选择本命元素；后续元素通过战利品进入仓库，可选择放置、融合或出售。用真实操作展示一次元素获取和一次融合，说明选择如何改变阵容。
2. **地形与阵位共同影响布阵。** 四张地图具有不同的路线与入口结构；高台、灵泉、地脉、狭道等阵位提供不同收益。展示同一元素塔在不同阵位上的实际差别，避免仅以地图外观作为创新依据。
3. **三维表现与移动交互结合。** 元素塔、能量体小怪、精英与 Boss 具有不同的造型层级；通过紧凑藏灵台、按需出现的操作信息和横屏安全区布局，提高小屏幕上的可观察性与可操作性。

上述内容为本作设计特点，不宣称“国内首创”或“行业领先”。

## 3. 技术与美术实现

- 使用 HTML、CSS 与 JavaScript 构建页面、状态与输入流程；战斗规则由游戏逻辑模块管理。
- 使用 Three.js／WebGL 实时呈现三维场景、塔、敌人与攻击表现，渲染层读取游戏状态。
- 使用 Capacitor 将同一网页资源打包为 Android 应用，配置横屏及沉浸式窗口。
- 首页与地图选择使用 AI 辅助生成的二维场景美术；地图卡片叠加从实际地图数据生成的路线和阵位示意。选择页美术并不代表战斗地形已经达到相同的预渲染细节。
- 仓库通过模型包围范围调整透明画布与相机上沿，完整呈现较高的塔模型，同时保持底部交互区域紧凑。

## 4. 成果状态
