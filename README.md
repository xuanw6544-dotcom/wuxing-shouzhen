# 五行守阵

一个面向抖音小游戏方向验证的五行塔防原型。当前版本使用原生 HTML、CSS 和 Canvas，无第三方依赖。

## 试玩

直接用浏览器打开 `index.html`。

## 已实现

- 山门主页面，选择地图、本命元素与挑战模式后入阵
- 横屏四段式流程：山门首屏 → 地图/模式 → 本命元素 → 战斗；手机竖屏时提示旋转设备
- 横屏战斗采用主战场加右侧操作栏，不需要纵向滚动
- 青岚古阵、双溪峡谷、回环遗迹三张不同路线和阵位的地图
- 每十波一章，渐进、分批、密集、交错波次；Boss 按金木水火土每十波轮换
- 下一波预告与实际生成共用 `world.js` 配置，展示属性、数量、节奏和入口
- 定序试炼（壹）：同地图、同本命拥有相同波次与掉落序列；独立随机流避免战斗消耗改变掉落
- 地图与模式分别保存本机最佳守成波次、击退数、本命、战斗时长和最终阵型
- 返回山门会暂停当前战局，可继续守阵；刷新页面只保留纪录和声音设置，不保留进行中的战局
- 开局选择一种本命元素，商店只出售对应的基础塔
- 精英战后掉落元素核心，可收入三格元素栏、落阵成塔或与现有塔融合
- 十种双元素融合塔及独立战斗机制
- 五行相克：克制伤害 2 倍，被克制伤害 0.55 倍
- 五行相生：相邻的母子元素塔获得威力和攻速增益
- 纯元素三级强化自身能力，冰、毒、雷等特殊形态来自元素融合
- 无限生存波次，每波精英、每十波元素 Boss，敌人强度持续成长
- 融合专属效果采用第三击触发或 75%/82%/89% 等级概率
- 水球、火球、冰晶、毒孢和雷柱等差异化攻击表现
- 精英与 Boss 可攻击、灼烧、缠绕或沉默防御塔
- 防御塔拥有生命、损毁恢复和波次间金币修复机制
- 防御塔升级会提高攻击速度、生命和技能触发概率
- 防御塔升级、出售、修复、暂停和重新开始
- 鼠标与触屏操作，自适应手机尺寸

## 美术与声音

- `home-art.js` 实时绘制云海山门、石阶和五行祭坛，支持轻微视差与减少动态效果偏好。主背景生成服务失败后使用本地 Canvas 美术，无外部图片请求。
- 东方灵器风格：5 种基础塔、10 种融合塔、5 类元素造物，以及精英和 Boss 冠饰。
- `art.js` 负责 Canvas 造型、缓存地形和界面肖像，无需下载外部素材。
- `audio.js` 提供原创五声音阶背景音乐与合成攻击音效。首次点击或按键后启动声音。
- 右上角声音按钮可调节总音量、背景音乐、战斗音效和静音；设置保存在本机。
- 暂停时音乐淡出，切到后台时暂停音频，返回后继续。
- `scripts/visual-qa.cjs` 使用 Playwright 检查桌面与手机布局并生成 `artifacts/` 截图，需要本机提供 `playwright-core` 和 Edge。
- `scripts/world-qa.cjs` 检查波次、地图路线、Boss 轮换、定序掉落、继续守阵和本机战绩。
