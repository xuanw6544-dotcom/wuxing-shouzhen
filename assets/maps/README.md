# Map Selection Illustrations

Four WebP environment illustrations for map selection, generated with the built-in image generation tool using the approved home sanctuary as a style reference.

Source atlas: `exec-e1e39142-b072-46a7-a510-90a1440d8f0d.png`, retained in the local generation archive. Each of the four quadrants was extracted and encoded as WebP at quality 87; runtime dimensions are 836 x 470.

| Asset | Subject |
| --- | --- |
| qinglan-v1.webp | Jade mountain terraces and an ancient winding approach |
| shuangxi-v1.webp | Twin bridges, a turquoise gorge and waterfalls |
| huihuan-v1.webp | Overgrown stone ruins around a central chasm |
| wuxingchi-v1.webp | A heavenly pool with five elemental crystals |

These are selection illustrations, not screenshots of playable terrain. The live route and slot diagrams are drawn separately from `GameWorld.maps`.

Prompt summary: create an equal 2x2 environment atlas with no text or UI, matching the hand-painted Chinese fantasy sanctuary style; differentiate jade terraces, twin-stream gorge, circular ruins and five-element pool, while keeping the central islands readable when cropped into tall selection cards.
